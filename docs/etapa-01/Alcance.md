# Alcance



El sistema permitirá a los usuarios gestionar las operaciones del Pet Shop del Litoral. Dependiendo del rol asignado, los usuarios podrán consultar y gestionar productos, categorías, stock, clientes, ventas, compras y proveedores. Además, permitirá registrar ventas y compras, gestionar métodos de pago y consultar la información correspondiente a las operaciones realizadas. El producto de software está ideado primeramente con un alcance local para la ciudad de Corrientes, Corrientes, Argentina.
